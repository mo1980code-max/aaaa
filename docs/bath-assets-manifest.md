# غرفة الاستحمام — قائمة الأصول الرسومية (Assets Manifest)

**المشهد:** `BathScene` — دقة اللعبة المرجعية **1920 × 1080** (Landscape 16:9).
**الصيغة:** PNG-24 بقناة شفافية (Alpha)، مع نسخة WebP اختيارية لكل أصل بنفس الاسم (`.webp`) لتقليل الحجم.
**المسار:** `public/assets/bathroom/`
**قاعدة التسمية:** `snake_case`، والاسم البرمجي (Texture Key) مطابق لاسم الملف بدون الامتداد.

> نقطة الارتكاز الافتراضية في Phaser هي مركز الصورة (0.5, 0.5) — جميع الإحداثيات في الكود مبنية على ذلك.
> الأبعاد أدناه بدقة @1x (مطابقة لدقة اللعبة). يُفضَّل تصدير المصدر بدقة @2x ثم التصغير.

## اعتبارات تقنية

- **Trim/Padding:** تصدير كل أصل مقصوصاً على حدود البكسلات الفعلية (بدون هوامش فارغة) + هامش 2px لتفادي النزيف عند التحجيم.
- **WebP Fallback:** `this.load.image(key, [key + '.png'])` حالياً؛ عند توفر WebP تُستخدم صيغة Phaser: `{ key, url: '... .webp' }` مع فحص دعم المتصفح.
- **خط القص:** الحافة العلوية الداخلية لـ `tub_front` يجب أن تكون خطاً أفقياً نظيفاً (بدون تعرّجات كبيرة) لأن Geometry Mask سيقص جسم الطفل عنده.
- **ترتيب الطبقات (Depth):** `bath_bg (0) → tub_back (10) → water_surface (20) → Baby (30) → tub_front (40) → faucet/shower/soap/towel/UI (50+)`.
