# 🍼 Baby Care World - عالم رعاية الأطفال

لعبة رعاية أطفال تفاعلية مبنية بـ HTML5 و Phaser 3.

## 🎮 وصف اللعبة

لعبة رعاية أطفال متكاملة بتصميم كرتوني احترافي، مستوحاة من ألعاب رعاية الأطفال التفاعلية. يستطيع اللاعب رعاية طفل افتراضي في منزل تفاعلي يحتوي على 6 غرف مختلفة.

## 🛠️ التقنيات المستخدمة

- **Phaser 3** - محرك اللعبة
- **HTML5 Canvas** - الرسم والعرض
- **Vite** - بناء المشروع
- **Capacitor** - تحويل إلى Android APK/AAB
- **SVG/Canvas Graphics** - رسومات مولدة برمجياً

## 🚀 التشغيل

### المتطلبات
- Node.js 18+
- npm 9+

### التثبيت والتشغيل

```bash
# تثبيت التبعيات
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة النهائية
npm run build

# معاينة النسخة النهائية
npm run preview
```

## 🏠 الغرف التفاعلية

| الغرفة | الوصف | الأنشطة |

## 💰 نظام المكافآت

- **العملات 🪙**: تُكسب من الأنشطة (5-8 عملات لكل نشاط)
- **النجوم ⭐**: تُكسب من الإنجازات (1-2 نجمة)
- **الملابس 👗**: تُفتح بالعملات (قريباً)

## 📱 تحويل إلى Android

```bash
# تثبيت Capacitor
npm install @capacitor/core @capacitor/cli
npm install @capacitor/android

# إضافة منصة Android
npx cap add android

# بناء المشروع
npm run build

# مزامنة مع Android
npx cap sync android

# فتح في Android Studio
npx cap open android
```

## 🔒 سياسات الإعلانات (AdMob)

نظام الإعلانات معطل حالياً لاعتبارات سلامة الأطفال. قبل التفعيل:
- التحقق من التوافق مع Google Play Families Policy
- التحقق من التوافق مع COPPA
- استخدام إعلانات غير مخصصة فقط
- عدم تفعيل الإعلانات إلا بعد التحقق من ملاءمتها للأطفال
