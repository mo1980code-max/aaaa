# Baby Care World

لعبة رعاية أطفال باللغة العربية مبنية باستخدام Phaser 3. زر غرف المنزل لإطعام الطفل، وتحميمه، ومساعدته على النوم واللعب. تكسب العملات من أنشطة الرعاية والنجوم بعد كل خمس رعايات، ويمكن استخدام العملات لشراء الإكسسوارات.

## التشغيل محلياً

تُقدَّم اللعبة كملفات ثابتة. من مجلد المشروع شغّل:

```bash
python3 -m http.server 8000
```

ثم افتح <http://localhost:8000>. يلزم اتصال بالإنترنت لتحميل Phaser 3 من CDN. يمكن فتح `index.html` عبر أي خادم ملفات ثابت يدعم المسارات النسبية.

## الشخصيات

رسوم الشخصيتين المتجهية موجودة في `public/assets/characters/`، وتُحمَّل عند بدء اللعبة. إذا تعذّر تحميل أحد الملفين، تستخدم اللعبة رسماً احتياطياً مولّداً محلياً.

## حفظ التقدّم

تُحفَظ العملات والنجوم واحتياجات الطفل والشخصية والإكسسوارات تلقائياً في `localStorage` على الجهاز الحالي. إعادة ضبط التقدّم متاحة من شاشة الإعدادات.

## بناء نسخة ثابتة

```bash
./build-onefile.sh
```

ينشئ الأمر نسخة جاهزة للنشر داخل `dist/`، مع ملف اللعبة المصغّر وصفحة HTML ورسوم الشخصيات.
